设计说明

  • 状态机：ready → running ⇄ paused → over；进入页面为 ready， overlays 提供各状态唯一主按钮（开始 / 继续 / 再来一局）。
  • 键位：方向键 / WASD 转向，空格 / J / Shift 跳跃（空格是主操作键：未开始 = 开始、已暂停 = 继续），P / Esc 暂停或继续，Enter 在结束后重开；监听挂在 window 上，弹窗打开或焦点在输入控件时不拦截；点击按钮后主动 blur，避免空格误触按钮（同打字页）。
  • 伪 3D：棋盘 perspective + rotateX(16deg) 倾斜，加深下边框模拟板厚，大面积柔和投影制造悬浮；蛇身与障碍用上缘受光 / 下缘背光的双 inset 阴影 + 落地投影形成积木方块；遮罩层是棋盘平级兄弟节点，保持正对用户。
  • 无限地图：世界无边界，21×21 棋盘是跟随蛇头的相机窗口（类似土豆兄弟）；岩石按世界坐标哈希确定性生成，同一位置永远是同一障碍，无需存储；岩簇间缝隙天然可穿行，开局区域保证留空。
  • 地形：值噪声（粗网格哈希 + 双线性平滑）把世界分成草地、沙漠、海洋，边界是有机的不规则形状；草地是棋盘底色，沙漠是装饰地面，海洋是危险地形——走进去和撞岩石一样结束，跳跃可越过窄水面；食物只刷在可站立地面，出生点附近固定为草地安全区。
  • 食物：常驻 3 个，刷新在蛇头周围 6–15 格的环形带内（避开岩石与蛇身），吃掉补一个，距蛇头超过 22 格的自动丢弃。
  • 跳跃：腾空 3 个 tick，空中可越过障碍与自身但吃不到食物和道具；落地格必须为空，否则失败；落地后冷却 5 tick，统计行实时显示 就绪 / 空中 / 冷却。腾空表现：整条蛇明显上抬、蛇身泛白光、蛇头两侧扇动白色小翅膀，原位置留下椭圆投影，起跳瞬间脚下爆出一圈扬尘。
  • 道具：每种至多 1 个，在对应环境附近必定刷出（距环境 3–8 格的可站立地面；附近没有合适环境就不刷，吃掉或跑远后自动补刷）。金色菱形「碎岩」对应岩石，吃下后 5 秒内撞上岩石会将其永久撞碎（本局不再出现），碎裂时有碎片飞散和画面微震；蓝色水滴「游泳」对应水面，吃下后 10 秒内需水面也安全，生效期间棋盘四周泛蓝色光晕、入水时加深；紫色三角「飞行宝石」刷在水面或岩石附近，吃下后 5 秒持续飞行（比跳跃抬得更高、翅膀扇动更快、头后拖速度线）且移动加速约 1.5 倍，飞行中无视一切地形与自身、可照常拾取，效果结束时落点必须安全。跳跃腾空时吃不到食物和道具。吃到道具弹出顶部横幅提示，棋盘底部显示能力倒计时进度条，蛇身同时带对应颜色描边。
  • 统计：.snake-stats 用 role="status" 播报得分、最高、长度、跳跃状态、用时，数字等宽；棋盘 role="img" + aria-label 给出文字摘要。
  • 视野：窗口边长可配置（近 15 / 标准 21 / 远 27 格，取奇数保证蛇头居中）；格子尺寸 = 棋盘宽 ÷ 视野格数，视野越大看到的地图越广；食物刷新环随视野缩放。工具栏与设置分区共享该配置。
  • 尺寸：棋盘像素边长可配置（自动 / 小 400 / 中 560 / 大 720）；「自动」取列宽与「窗口高度 - 界面开销」的较小值，大屏幕自动铺满可用空间且不超出窗口；格子随棋盘等比缩放，与视野是两组独立调节。
  • 持久化：速度、障碍、视野、网格与最高分经 createModuleSettings 存 localStorage；写入失败沿用 usePersistError 的 ui-feedback--error 提示。
  • 配色：蛇身、食物、岩石与地形（草地 / 沙漠 / 海洋）为游戏图形用色，模块内以 light-dark() 局部定义；工具栏、状态卡与反馈仍全部使用公共 token，不新增主题。
  • 渲染：实现为单张 <canvas> + requestAnimationFrame（render.ts）：地形、网格、岩石、食物、蛇身、飘分逐帧绘制，游戏区 DOM 只剩状态遮罩，帧开销与元素数量无关；棋盘像素边长经 ResizeObserver 供给渲染循环，buffer 按 devicePixelRatio 分配，主题色从 CSS 变量解析。设计稿用 .snake-ground--* / .snake-grid / .snake-seg 等 DOM 静态等价物表达同一视觉。
  • 动效：蛇身每帧在最近两个 tick 状态之间做亚格插值，是真·平滑爬行而非格间滑动；蛇头眼睛随方向偏置、食物呼吸脉动、吃食 +1 飘分、撞死时棋盘震动且蛇头标红；prefers-reduced-motion 下 DOM 侧动效全部回退。
  • 相机：相机是画布内的小数坐标，按指数平滑（时间常数 ~1.8 tick）追踪蛇头——蛇会在视野里领先一小段再被平滑追上，而不是钉死在中心；重开一局时相机直接归位，不会整屏飞越。
